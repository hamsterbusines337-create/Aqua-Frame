# Aqua Frame 1.0

## Текущий этап

Фундамент Windows, нативная навигация, оформление, библиотека, Aqua Scripts и сброс профиля есть в исходниках. Работа продолжается в этапах функций браузера, безопасности, производительности и совместимости.

## Реализовано в исходниках

- Win32, CMake, C++20, CEF 158.0.6. Используется Chrome Runtime. Встраиваемый HWND работает в стиле Alloy CEF для собственного браузерного интерфейса.
- Официальный bootstrap для Windows передаёт данные sandbox, приложение завершает запуск при их отсутствии.
- Вкладки, закрытие и восстановление вкладки в пределах сессии, адресная строка, Google, переход назад и вперёд, обновление, базовые горячие клавиши.
- Тёмно-синяя тема, размеры вкладок 36 и панели 40 логических пикселей, обработка смены DPI. Статическая локальная страница с логотипом и четырьмя ссылками.
- Windows CI, подготовка CEF, выпуск Release, сценарий проверки появления окна и дочернего renderer, Inno Setup и ZIP.
- `aqua://settings` сохраняет настройки запуска, поиска и масштаба. Два режима сброса. Полный сброс после подтверждения передаёт блокировку профиля отдельному помощнику, который очищает профиль и перезапускает браузер.
- Aqua Scripts импортирует `.js` и `.user.js` через выбор файла или перетаскивание на верхнюю панель главного окна. В настройках можно отключить и удалить сохранённые скрипты. Скрипт выполняется в изолированном мире на явно одобренном HTTP(S)-сайте. GM API, удалённые зависимости и `document-start` пока не поддерживаются.
- История, закладки и панель закладок, список загрузок текущего запуска, группа «Работа» и группа «Учёба», перестановка, закрепление и дублирование. Контекст инкогнито хранит данные в памяти и очищается после закрытия последней приватной вкладки.
- Восстановление сессии откладывает загрузку фоновых вкладок до выбора. Шрифт панели переиспользуется при изменении размеров окна. Новая вкладка рисует статичные волны и показывает недавние сайты в обычном профиле. Анимация карточек учитывает системную настройку уменьшенного движения.
- HTTPS-Only для переходов основного фрейма. Выбор разрешений камеры, микрофона, геолокации, уведомлений и буфера обмена для HTTPS-сайтов в нативном диалоге.
- Aqua Performance по запросу собирает Navigation Timing, интервалы rAF страницы и снимок процессов Windows. Метрики FPS нативного интерфейса, GPU и задержки ввода ещё нужны. Сетевое RTT и шахматные FPS требуют измерений на реальном ПК.

## Следующие этапы

- Проверить навигацию, запуск установщика и распакованного ZIP.
- Доработать визуальное соответствие. Панель инструментов, меню и страницы настроек и расширений требуют доработки и сравнения.
- Добавить поисковые подсказки и автодополнение, редактируемые быстрые ссылки и фон, управление пользовательскими профилями, устойчивое восстановление после аварии, приостановку неактивных вкладок с исключениями и явные режимы производительности, архив загрузок, пользовательские имена групп.
- Проверить заявленные расширения и совместимость Chrome Web Store. Доработать Aqua Scripts до редактора, экспорта, журнала, дополнительных GM API и явной политики для зависимостей.
- Доработать Aqua Security и Aqua Privacy. Управление разрешениями и данными по сайту, DNS over HTTPS, блокировка сторонних cookies и трекеров, проверка опасных загрузок, хранилище паролей. Для защищённых Windows-обновлений нужны подпись доверенного издателя и проверка подписанного релиза при установке.
- Расширить тесты защиты внутренних страниц и выполнить измерения Chrome и Aqua Frame на одном оборудовании. Исходные ориентиры пользователя составляют 12 FPS на Chess.com и 53 FPS на Lichess.

Автоматическая смена внешнего IP требует согласованного VPN или прокси-провайдера. Текущая сборка использует обычное сетевое подключение Chromium. Смена IP для новых соединений и сохранение уже открытых соединений зависят от сетевой архитектуры.

## iPhone

Добавлена отдельная версия для iOS 17+ на SwiftUI и WebKit с темой Aqua Deep Ocean. Доступны вкладки, частные вкладки, HTTPS-навигация, поиск Google и закладки. GitHub Actions собирает приложение для симулятора и запускает UI-тест. Установка на физический iPhone требует отдельной подписи Apple. См. [инструкцию для iOS](ios/README.md).
