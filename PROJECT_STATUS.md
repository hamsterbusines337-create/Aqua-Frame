# Aqua Frame 1.0

## Текущий этап

Этапы 1–3 начаты. Первая Windows Release-сборка успешно завершилась и опубликовала артефакты. Статус выпуска для повседневного использования ещё не достигнут.

## Реализовано в исходниках

- Win32, CMake, C++20, CEF 158.0.6. Используется Chrome Runtime. Встраиваемый HWND работает в стиле Alloy CEF для собственного браузерного интерфейса.
- Официальный bootstrap для Windows передаёт данные sandbox, приложение завершает запуск при их отсутствии.
- Вкладки, закрытие и восстановление вкладки в пределах сессии, адресная строка, Google, переход назад и вперёд, обновление, базовые горячие клавиши.
- Тёмно-синяя тема, размеры вкладок 36 и панели 40 логических пикселей, обработка смены DPI. Статическая локальная страница с логотипом и четырьмя ссылками.
- Windows CI, подготовка CEF, выпуск Release, сценарий проверки появления окна и дочернего renderer, Inno Setup и ZIP.

## Проверено

- Из официального индекса загружен Windows x64 minimal CEF. Сверены SHA-1, размер и SHA-256. Проверено наличие bootstrap, ресурсов и API CEF.
- [Windows Actions 45770912364](https://github.com/hamsterbusines337-create/Aqua-Frame/actions/runs/45770912364), коммит `1f55819`. Автотест увидел окно и процесс Chromium renderer и подтвердил выход с кодом 0. Опубликованы установщик, портативный ZIP и комплект AquaFrame.exe с библиотеками.
- Устранены задержка распаковки CEF в CI, ошибки отсутствующих заголовков и зависание при закрытии окна.
- Запуск из установщика и из распакованного ZIP, работа GPU, производительность шахматных сайтов и визуальное сравнение пока не проверены.
- В меню Aqua Frame и по адресу `aqua://extensions` открывается тёмное окно Aqua Frame с собственным логотипом и встроенной страницей Chromium того же профиля. Его штатная страница расширений принимает перетаскиваемые ZIP и CRX после включения режима разработчика.
- [Windows Actions 45785842225](https://github.com/hamsterbusines337-create/Aqua-Frame/actions/runs/45785842225), коммит `9125592`. Проверены сборка с фирменным окном и автотест открытия и закрытия. [Снимок окна](https://raw.githubusercontent.com/hamsterbusines337-create/Aqua-Frame/6e74899c9644d8331953646d1e668ce9bb81dabd/AquaFrame-Extensions-Dark.png).
- [Windows Actions 45778897340](https://github.com/hamsterbusines337-create/Aqua-Frame/actions/runs/45778897340), коммит `eab12f7`. Автотест подтвердил открытие менеджера и штатное завершение. На CI не удалось подтвердить установку файла через эмулированное Windows OLE-перетаскивание. Совместимость конкретных расширений и Chrome Web Store ещё не проверена.

## Следующие этапы

- Проверить навигацию, запуск установщика и распакованного ZIP.
- Доработать визуальное соответствие. Панель инструментов, меню и страницы настроек и расширений требуют доработки и сравнения.
- Продолжить реализацию памяти вкладок, истории, закладок, загрузок, профилей, расширений, Aqua Scripts, безопасности и разрешений, приватности, полного сброса, подписанных обновлений и монитора производительности.
- Выполнить тесты защиты внутренних страниц и заводского сброса на искусственном профиле, затем измерения Chrome и Aqua Frame на одном оборудовании. Исходные ориентиры пользователя составляют 12 FPS на Chess.com и 53 FPS на Lichess.

## iPhone

Добавлена отдельная версия для iOS 17+ на SwiftUI и WebKit с темой Aqua Deep Ocean. Доступны вкладки, частные вкладки, HTTPS-навигация, поиск Google и закладки. GitHub Actions собирает приложение для симулятора и запускает UI-тест. Установка на физический iPhone требует отдельной подписи Apple. См. [инструкцию для iOS](ios/README.md).
