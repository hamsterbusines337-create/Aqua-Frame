# Aqua Frame

Нативный браузер Windows x64 на C++20 и готовых бинарных файлах Chromium Embedded Framework. Текущая версия исходников покрывает начальный этап разработки. Beyond the ordinary.

## Сборка

Требуются Visual Studio 2022 с инструментами C++ x64, Windows SDK и CMake 3.24+. Запустите `setup.bat`, затем `build.bat` и `run.bat`. Для создания установщика нужен Inno Setup 6. Скрипт `scripts/package.ps1` собирает установщик и ZIP из Release.

GitHub Actions запускает Release-сборку и проверку запуска на `windows-2022`. В успешном запуске раздел **Artifacts** содержит установщик, портативный ZIP, SHA-256 и перечень версий CEF. Отдельный артефакт содержит `AquaFrame.exe` с необходимыми файлами. Распаковывайте архив целиком. Для портативного каталога, если Windows не предоставляет права процессам песочницы по наследованию, выдайте доступ на чтение и выполнение только подготовленному каталогу Aqua Frame командой из этого каталога:

```cmd
icacls "." /grant "*S-1-15-2-2:(OI)(CI)(RX)"
```

Профиль по умолчанию хранится в `%LOCALAPPDATA%\Aqua Frame\User Data`. Портативный архив запускается без установки и использует тот же каталог профиля.

## CEF и обновления

Сборка закреплена на CEF 158.0.6 и Chromium 158.0.8127.89. Подготовка проверяет размер и SHA-1 по официальному HTTPS-индексу, а также закреплённый SHA-256. Для смены версии подготовьте чистую папку CEF и передайте в `setup.bat` параметры `-Version` и `-Sha256` с проверенными значениями. Выпуск продуктов с проверкой подлинности и безопасным откатом требует подписания собственных DLL и установщика. Текущие артефакты CI предназначены для разработки и проверки.

Подробности в [PROJECT_STATUS.md](PROJECT_STATUS.md).

## Настройки и сброс в Windows

Откройте **☰ → Настройки** или введите `aqua://settings`. Можно выбрать поисковую систему, настроить восстановление вкладок после штатного закрытия и изменить масштаб веб-страниц.

В разделе **Сброс браузера** обычный сброс восстанавливает настройки по умолчанию и сохраняет данные сайтов. Полный сброс требует отдельного подтверждения, закрывает CEF и очищает каталог `%LOCALAPPDATA%\Aqua Frame\User Data` через упакованный помощник `AquaFrameReset.exe`. При успешной очистке открывается экран первого запуска. Сброс сохраняет файлы вне профиля. Если системная папка загрузок расположена внутри профиля, очистка останавливается. При обнаружении незавершённой очистки следующий запуск пытается продолжить её. Очистка удаляет файлы обычным способом.

## Перетаскивание расширений в Windows

В Aqua Frame нажмите **☰ → Расширения — перетащить файл** или **Ctrl+Shift+E**. Откроется тёмное окно «Расширения — Aqua Frame» для того же профиля. Внутри используется встроенная страница управления расширениями Chromium. Включите **Режим разработчика** и перетащите один файл `.zip` или `.crx` из Проводника прямо на страницу. Для ZIP требуется `manifest.json` в корне архива. Устанавливайте пакеты только из доверенных источников. Chromium проверяет пакеты и определяет, разрешена ли установка. Часть функций расширений, которым нужна панель Chromium, доступна только в окне менеджера.

## Импорт JavaScript в Aqua Scripts

Откройте сайт, на котором должен работать скрипт. Нажмите **Ctrl+Shift+E → Aqua Scripts · импорт JS → Выбрать файл JS** или перетащите один `.js` или `.user.js` из Проводника на верхнюю панель главного окна браузера. Проверьте адрес в диалоге, разрешите доступ и обновите страницу сайта. Aqua Scripts запоминает разрешение только для указанной схемы, домена и порта. В `aqua://settings/#scripts` можно выключить или удалить скрипт. Изменение действует после перезагрузки страницы. Полный сброс очищает библиотеку вместе с профилем.

Размер одного файла UTF-8 ограничен 512 КиБ. Для `.user.js` поддерживаются `@match`, `@include` и `@exclude` с шаблонами, `@exclude-match`, `@grant none` и `@run-at document-end` или `document-idle`. Для скриптов, которым нужны GM API, `@require`, `@resource` или `document-start`, пока потребуется совместимый менеджер расширений. Для импорта нужен исходный JavaScript. Содержимое `user.json` и пакеты с `manifest.json` обрабатываются отдельно.
