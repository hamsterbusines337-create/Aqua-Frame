# Aqua Frame для iPhone

Нативное приложение для iOS 17 и новее. Интерфейс на SwiftUI, просмотр страниц через системный WKWebView. Реализованы адресная строка с Google, локальный стартовый экран, вкладки, частные вкладки с непостоянным хранилищем, навигация и локальные закладки. Приложение использует штатную проверку сертификатов WebKit и принимает HTTPS для навигации. Расширения CEF, Aqua Scripts, десктопный профиль и функции Windows не перенесены.

## Проверка

В GitHub Actions запустите **Aqua Frame iPhone**. Задание генерирует проект, запускает тест на симуляторе и публикует архив приложения симулятора. Этот архив запускается в симуляторе iOS на Mac.

На Mac с Xcode и XcodeGen из каталога `ios` выполните `xcodegen generate` и откройте `AquaFrame.xcodeproj`.

## Установка на iPhone

Для TestFlight настройте уникальный Bundle Identifier и Signing Team в Xcode, создайте запись приложения в App Store Connect, выполните Archive, загрузите сборку и пригласите тестировщика. Для этого нужен доступ к команде Apple Developer Program. Для тестирования собственного приложения без платного участия можно выбрать Personal Team в Xcode и запустить сборку на своём iPhone с доступного Mac. Этот способ требует периодического продления подписи.

Репозиторий и CI не содержат учётных данных Apple и не публикуют приложение в App Store Connect.
